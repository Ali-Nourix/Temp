# هشت کاتالوگ دیجیتال — نمونه‌های طراحی

Eight digital brand catalogs, each a different design language, built on one
shared design system and one shared interaction layer.

## لینک آنلاین

**<https://ali-nourix.github.io/Temp/>**

صفحه‌ی اول همه‌ی نمونه‌ها را فهرست می‌کند. اگر لینک باز نشد، یعنی GitHub Pages
هنوز روشن نشده است:

> Settings ← Pages ← زیر **Build and deployment**، در Source گزینه‌ی
> **Deploy from a branch** و بعد برنچ `claude/vigilant-davinci-gomzs5` و
> پوشه‌ی `/ (root)` ← Save

یکی دو دقیقه بعد آدرس بالا بالا می‌آید. آدرس به برنچ بستگی ندارد؛ هر برنچی را
که انتخاب کنید همین آدرس سرو می‌شود.

بدون Pages هم می‌شود فایل‌ها را از `catalogs/` دانلود کرد و مستقیم باز کرد —
هر کدام یک فایل کامل و مستقل است.

## مکانیزم رسانه — در هر هشت نمونه

این چیزی است که در همه‌ی نمونه‌ها یکسان کار می‌کند:

- **جزئیات روی عکس** — کلیک روی تصویر محصول، بزرگ‌نمایی روی همان نقطه‌ای که
  کلیک کردید. کشیدن برای جابه‌جایی، چرخ ماوس و pinch برای زوم.
- **نقطه‌های جزئیات** — نقطه‌های شماره‌دار روی خود تصویر که به بخش واقعی محصول
  چسبیده‌اند و با زوم و جابه‌جایی همراه می‌شوند؛ کلیک، توضیح آن بخش را می‌آورد.
- **پخش ویدیو** — نوار زمان واقعی: پخش، مکث، جابه‌جایی روی تایم‌لاین، بی‌صدا،
  و ساعت زنده. روی کارت محصول هم با هاور یک پیش‌نمایش بی‌صدا اجرا می‌شود.
- **چرخش ۳۶۰ درجه** — با کشیدن، محصول می‌چرخد و زاویه نمایش داده می‌شود.
- صفحه‌کلید: `Esc` بستن، `←/→` جابه‌جایی یا seek، `Space` پخش/مکث، `+/-` زوم.

## عکس و ویدیوی واقعی

تصویرها جانگهدارِ ساخته‌شده‌اند — هر محصول از روی یک seed به شکل قطعی رسم می‌شود،
بدون شبکه و بدون عکس استوک. مکانیزم‌ها اما واقعی‌اند. برای گذاشتن فایل واقعی،
در توصیف‌گر رسانه `src` را بدهید:

```js
{ type: 'photo', src: 'assets/SK-101-front.jpg',
  hotspots: [ { x: 50, y: 38, title: 'بدنه', body: '…' } ] }

{ type: 'video', src: 'assets/SK-101.mp4', poster: 'assets/SK-101-poster.jpg' }
```

ویدیو آن‌وقت از یک `<video>` واقعی پخش می‌شود و بقیه‌ی کنترل‌ها بدون تغییر
کار می‌کنند. مختصات `x` و `y` نقطه‌های جزئیات درصدی از خود تصویرند، نه از صفحه.

## ساختار

```
index.html              فهرست — ساخته می‌شود، ریشه چون Pages همین را سرو می‌کند
catalogs/*.html         خروجی — هر کدام یک فایل مستقل و کامل
shared/ds-core.css      توکن‌ها، ۸ تم، و لایه‌ی کامپوننت‌های .cat-*
shared/catalog-kit.js   تصویرسازی، نمایشگر جزئیات، پخش‌کننده، چرخش
shared/BRIEF.md         قرارداد ساخت هر نمونه
src/*.html              سورس هر نمونه (به فایل‌های مشترک لینک می‌دهد)
build.py                فایل‌های مشترک را داخل هر سورس تزریق می‌کند
.nojekyll               تا Pages فایل‌ها را همان‌طور که هستند سرو کند
```

```bash
python3 build.py                       # همه
python3 build.py 01-editorial-single.html   # یکی
```

خروجی `catalogs/` عمداً در گیت نگه داشته شده — همین فایل‌ها محصول نهایی‌اند و
باید بدون ساختن، مستقیم باز شوند.

## قواعدی که همه‌ی نمونه‌ها رعایت می‌کنند

RTL فارسی اول · دوزبانه با یک کلید · هیچ رنگ خامی بیرون از توکن‌ها · بدون
ایموجی · بدون لورم ایپسوم و آمار ساختگی · هدف لمسی حداقل ۴۴ پیکسل · احترام به
`prefers-reduced-motion` · قابل چاپ.

فونت‌ها از Google Fonts می‌آیند و هر خانواده fallback سیستمی دارد، پس فایل
آفلاین هم درست رندر می‌شود.
